## 🚀 Featured Projects

### 📰 NEWSMAG – News Aggregation Web App
A responsive news app that shows real-time news across 7 categories with dynamic category switching.

- Built with **React.js** and **Bootstrap** using a card-based, responsive layout
- Integrated the **NewsData.io REST API** with the Fetch API
- State and data fetching handled with **React Hooks** (`useState`, `useEffect`), including loading and error states
- Reusable components: `Navbar`, `NewsBoard`, `NewsItem`
- ⚡ **Lighthouse performance score of 97**, LCP 1.2s (desktop), near-zero layout shift

🔗 [GitHub](https://github.com/Pooja970-web/NEWSMAG)

### 🪑 Exam Seat & Invigilation Allocator
A full-stack app that automatically generates exam seating plans and invigilator duty rosters.

- **Constraint-based seating algorithm** (greedy heuristic with randomized restarts): same-subject students are never seated side-by-side or front-back, with **zero clashes** on a 75-student test dataset
- **Fair invigilation allocator** that balances duty load, prevents double-booking and enforces a per-teacher duty cap
- **REST API** with Express.js and downloadable seating-plan and duty-roster **PDFs** using PDFKit
- Responsive UI with color-coded seating grids, CSV upload and summary stats (vanilla JavaScript)
- Deployed on **Render** with Git-based continuous deployment

**Tech:** Node.js, Express.js, PDFKit, JavaScript

🔗 [Live Demo](https://YOUR-RENDER-LINK.onrender.com) · [GitHub](https://github.com/Pooja970-web/-Exam-seat-invigilation-allocator-)
